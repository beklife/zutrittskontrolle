Über das Projekt

Diese Demo zeigt eine einfache Zutrittskontrolle für eine erfundene Spielhalle. Am Eingang wird geprüft, ob ein Spieler eintreten darf: Er muss mindestens 18 Jahre alt sein und darf nicht gesperrt sein. Jeder Versuch wird protokolliert. Das Personal kann Spieler anlegen und sperren.

Alle Namen und Daten sind erfunden. Die Daten werden jede Nacht um 3 Uhr zurückgesetzt.

Regeln

  1. Spieler gesperrt → Zutritt verweigert: gesperrt (diese Regel hat Vorrang)
  2. Spieler jünger als 18 → Zutritt verweigert: unter 18
  3. Sonst → Zutritt erlaubt

Technik

  • Backend: Java 21, Spring Boot, Spring Data JPA, Flyway, Bean Validation
  • Datenbank: PostgreSQL 16
  • Frontend: Angular (Standalone Components, Signals), SCSS
  • Tests: JUnit 5, Mockito, AssertJ, Testcontainers, MockMvc, Playwright mit axe
  • Betrieb: Docker, docker-compose, Traefik mit Let's Encrypt, GitHub Actions
